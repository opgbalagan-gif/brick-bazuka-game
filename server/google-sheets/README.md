# Общий рейтинг BRICK BAZUKA

Рейтинг использует тот же Google Apps Script, что и SOLLERS Traffic Rush. `Code.gs` содержит исходные обработчики SOLLERS и отдельные обработчики BRICK BAZUKA. При обновлении общего проекта загружайте файл целиком, чтобы сохранить обе игры.

- Проект: https://script.google.com/home/projects/1MgXX-euTk9atCRvvuv9Or_wF9bTLvnKFRcNYZTkNXmQPEGAoARztlOVM/edit
- Публичный `/exec` URL задан в `scripts/leaderboard.gd`. Это адрес API, он не содержит ключей доступа.
- `setupBrickBazukaLeaderboard` создаёт отдельную закрытую таблицу и сохраняет её ID в `BRICK_SPREADSHEET_ID`. Повторный вызов использует существующую таблицу.
- Таблица SOLLERS, её настройки и API остаются отдельными. Секрет подписи остаётся в свойствах Apps Script.

## API

`GET ?action=brick_leaderboard` возвращает `{game: "brick-bazuka", rows: [{rank, name, score}], updatedAt}`: десять лучших забегов, при одинаковых очках раньше записанный результат выше.

`POST` с `Content-Type: text/plain;charset=UTF-8` принимает JSON. Такой запрос из браузера не вызывает CORS preflight; Google отвечает через перенаправление.

- `{action: "brick_runs"}` выдаёт ID и подписанный токен забега.
- `{action: "brick_scores", id, token, name, score}` записывает результат и возвращает `{game: "brick-bazuka", saved: true, rank}`.

Сервер проверяет подпись, срок токена, диапазон очков и имя длиной 2–20 символов. Формулы, управляющие символы и HTML-разметка в имени отклоняются. При сетевом сбое клиент повторяет тот же запрос: один забег не добавляется дважды. Публичный ответ содержит только место, имя и очки.

Результаты разделены по забегам: один игрок может публиковать несколько попыток. Имя — публичный псевдоним, оно не подтверждает личность. Физика остаётся на клиенте; проверка допустимой скорости набора очков даёт базовую защиту, а не полноценную защиту от читов.

Список обновляется при открытии, после сохранения и каждые 15 секунд, пока открыт экран результатов. При ошибке публикация не помечается успешной, доступен повтор. Google Apps Script требует интернета и имеет квоты; база не подменяется локальными рекордами.

## Проверки

`node scripts/test_leaderboard.mjs` проверяет общие результаты разных игроков, разделение двух игр, подписи, ограничения, приватность токенов, топ-10 и повторную отправку на изолированной модели Google Таблиц. Тест не записывает данные в настоящую таблицу.

После изменения кода создайте новую версию существующего развёртывания, сохранив `/exec` URL. Саму таблицу публиковать не нужно.
